def convolution_4_loops(img, filter):
  # Code assumes image is colored
  # flip filter for convolution
  filter = np.flip(filter)
  
  # makes sure filter 2d for colored images
  filter = np.atleast_2d(filter)

  input_img = img.copy()
  out_img = np.zeros_like(input_img)

  # add 0 padding for image
  pad_h = (filter.shape[0] - 1) // 2
  pad_w = (filter.shape[1] - 1) // 2
  input_img = np.pad(input_img, pad_width=((pad_h, pad_h), (pad_w, pad_w), (0, 0)), mode='constant')

  # apply kernel filter
  for row in tqdm(range(pad_h, input_img.shape[0] - pad_h)):
    for col in range(pad_w, input_img.shape[1] - pad_w):
      filter_sum = np.zeros((input_img.shape[2]))
      for k_row in range(filter.shape[0]):
          for k_col in range(filter.shape[1]):
            filter_sum += filter[k_row][k_col] * input_img[row - pad_h + k_row][col - pad_w + k_col]
      out_img[row - pad_h, col - pad_w] = filter_sum

  # if image is gray scale, remove unecessary shape which is added outside function
  if input_img.shape[2] == 1:
    return out_img.squeeze()
  return out_img

def convolution_2_loops(img, filter):
  # Code assumes image is colored
  filter = np.flip(filter)
  filter = np.atleast_2d(filter)

  input_img = img.copy()
  out_img = np.zeros_like(input_img)

  # add 0 padding for image
  pad_h = (filter.shape[0] - 1) // 2
  pad_w = (filter.shape[1] - 1) // 2
  input_img = np.pad(input_img, pad_width=((pad_h, pad_h), (pad_w, pad_w), (0, 0)), mode='constant')

  # apply kernel filter
  for row in tqdm(range(pad_h, input_img.shape[0] - pad_h)):
    for col in range(pad_w, input_img.shape[1] - pad_w):
      
      # portion of image kernel is applied to
      cropped = input_img[row-pad_h:row+pad_h+1, col-pad_w:col+pad_w+1]
      out_img[row - pad_h, col - pad_w] = np.sum(cropped * filter[:, :, np.newaxis], axis=(0, 1))

  # if image is gray scale, remove unecessary shape which is added outside of function
  if input_img.shape[2] == 1:
    return out_img.squeeze()
  return out_img

Part 2.1

Unsharp Mask Filter Implementation

The unsharp mask filter is done by taking and image and applying the gaussian kernel to it. You then take the original image and subtract the blurred image to capture only the high frequencies. You then add these high frequencies scaled by a factor alpha to the original image, creating a "sharpening" effect"

To make this more efficient, this can be simplified to a single kernel ((1 + alpha) * identity_kernel - alpha * gaussian_kernel)

Results

Comparing image 5, which was blurred than sharpened, to image 4, which was just sharpened, you can see that image 5 still has less details compared to image 4. This is because after blurring, you can't regain the details that were lost. This is applicable to low megapixel cameras. If the image your camera takes has low details, no amount of processing or sharpening can regain those lost details.

The above images show the results of varying the sharpness. With these exaggerated alpha values, you can see what sharpening is actually doing, which is multiplying the sharp changes or the edges.
