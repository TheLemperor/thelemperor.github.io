1.7.2 Inpainting
Implementation

I modified the sampling loop to preserve the original image outside the masked region at each timestep. Given an original image xorig and a binary mask m (where m=1 indicates the region to inpaint), I ran the normal denoising step to get xt, then force the pixels outside the mask to match the original image with appropriate noise: xt ← m · xt + (1 - m) · forward(xorig, t). The forward function adds the correct amount of noise to xorig for timestep t.

1.8 Visual Anagrams

Implementation

I modified the sampling loop to compute two noise estimates at each timestep. First, I compute ε1 by running CFG normally with prompt p1. Then, I flip the current image xt upside down, run CFG with prompt p2, and flip the output back to get ε2. The final noise estimate is the average ε = (ε1 + ε2) / 2.

1.9 Hybrid Images

Implementation

I modified the sampling loop to compute two noise estimates at each timestep and combine them in the frequency domain. First, I compute ε1 by running CFG with prompt p1, and ε2 by running CFG with prompt p2. Then I apply a Gaussian low-pass filter to ε1 and a high-pass filter to ε2, combining them as ε = flowpass(ε1) + fhighpass(ε2). The low-pass filter is a Gaussian blur with kernel size 33 and sigma 2, and the high-pass filter is computed as the original minus the low-passed version.

1.2.3 Denoising Pure Noise

After training for 5 epochs, I do not observe any recognizable digit patterns in the generated outputs. Instead, the results are just blurry and grayish blobs with slightly darker regions around the edges. This is expected behavior because the model is trained with MSE loss. It learns to predict the mean of all the training images. When given pure noise it is the average of all the digits, which does not resemble any specific digit.
